## ❓ Por que este curso existe?

Estamos vivendo a maior revolução tecnológica desde a internet: a Era dos Agentes de IA.
Não estamos falando de chatbots que só respondem perguntas. Estamos falando de sistemas inteligentes que agem, decidem e executam — automatizando tarefas complexas que antes exigiam equipes inteiras.

A questão não é SE sua empresa/carreira será impactada pela IA. É QUANDO — e se você estará preparado.

## 📚 O que você vai aprender

### 8 módulos progressivos (60 horas de conteúdo)

1) Fundamentos de IA Generativa (8h)
- LLMs, Transformer, tokenização, embeddings, multimodalidade
- Parâmetros de geração: temperature, top-p, top-k
- Projeto: Gerador de Ideias Multimodal

2) Engenharia de Prompts Avançada (6h)
- PCFT, Zero/Few-Shot, CoT, Self-Consistency, ToT, ReAct
- Projeto: Sistema de Análise de Sentimento com CoT

3) Frameworks – LangChain (10h)
- Chains, RAG, Agents, Memory, Tools, integrações
- Projeto: ChatPDF – Converse com seus documentos

4) Agentes com Agno (5h)
- Minimalismo, criação rápida de agentes, RAG e memória
- Projeto: Assistente Pessoal de Tarefas

5) Sistemas Multi-Agentes com CrewAI (12h)
- Orquestração de equipes de IA, processos, observabilidade
- Projeto: Agência de Criação de Conteúdo Automatizada

6) Model Context Protocol (MCP) (8h)
- Padronização de ferramentas, servidores MCP, interoperabilidade
- Projeto: MCP para Gerenciamento de Projetos

7) Deploy e Produção (6h)
- Arquiteturas de deploy, FastAPI, Docker, nuvem, custos
- Projeto: Deploy da Agência na Nuvem

8) Ferramentas e Ecossistema (5h)
- Hugging Face, modelos open-source, Ollama, fine-tuning
- Projeto: Ambiente de Desenvolvimento IA Completo
